# PWM 攻击寄存器图核对说明

图对应 `hdl/core/mlkem_poly_alu.sv` 的 `OP_BMUL` 路径。两个 `mlkem_modmul` 实例采用 Barrett 约减。图按参考图的黑白原生电路元件样式绘制，仅攻击目标使用红框。

时间以 RTL 中该字 RAM 读请求周期 T 为基准，寄存器旁标注的是寄存器输出对该字有效的周期。赋值语句后的注释有时指运算输入所在周期，不能直接当作结果寄存器的周期。

| 目标 | 红框中的有效周期 | 对应代码 |
|---|---|---|
| p00 / p11 | T+11 | mlkem_poly_alu.sv:207,269–270 |
| h0 | T+18，计算输入在 T+17 | mlkem_poly_alu.sv:213,286 |
| h1d[3] / h1d[4] | T+17 / T+18 | mlkem_poly_alu.sv:211–212,279,283–285 |
| wb | T+19，累加输入在 T+18 | mlkem_poly_alu.sv:206,290 |
| wbd | T+20，作为中间级展示 | mlkem_poly_alu.sv:206,291 |
| rb_din | T+21 | mlkem_poly_alu.sv:189,301,323 |

`h1d[0:2]` 对应 T+14–16，图中将其合并显示；`p00d[0:5]` 对应 T+12–17，仍然是六级真实延迟寄存器。图中以“若干 × REG”表示合并的寄存器链。

两个乘法器的输入复用完全对应 `mlkem_poly_alu.sv:225–235`：

- u_mul0 在 T+3 接收 a0、b0，在 T+4 接收 ksa、ksb。
- u_mul1 在 T+3 接收 a1、b1，在 T+10 直接反馈 m1_r 与 pg[10] 相乘；该反馈没有经过 p11。
- G 是绘图的同名连接标签，表示该字在 T+17 的 m1_r，不是新增的 RTL 寄存器。
- 低位/高位系数由 la、lb 拆位得到；MUX 输入中的同名系数均来自顶部定义的寄存器。

图中未修改原 RTL 或攻击模型，也未重新进行综合或硬件仿真。已核对寄存器声明、非阻塞赋值关系、位宽、连线与导出排版。
