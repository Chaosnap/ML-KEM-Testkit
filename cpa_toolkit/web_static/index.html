    Link settings

    host side, applied to the connected board and every reconnect
    Every operation is one 0x05 Run frame: the FPGA writes CTRL.start, stays silent until the core is done, then replies with STATUS, CYCLE_COUNT, ERROR_CODE and the result. There is no STATUS polling.
    Protocol reference: docs/UART_PROTOCOL.md

    Protocol steps

    one operation step by step — the SimpleSerial commands x / m / s / c / e / a
    x
    Reset
    CTRL ← RESET
    m
    Set mode
    SEC_LEVEL, OP_MODE, DATA_IN/OUT
    s
    Send secret key
    dk → 0x0000 (2400 B)
    c
    Send ciphertext
    c → 0x0960 (1088 B)
    e
    Run and wait
    START, reply when done
    a
    Get result
    read the output at 0x0E00
